# v0.2.0 concept art: chibi toy style

Higgsfield (`gpt_image_2_5`, quality high, 2k) with job `fff20d91-31be-4ce7-9554-0e6496665cf8` (style option 8a) as
the style reference, so pass that job id (or any job here) as `image_references` to keep new images consistent.
